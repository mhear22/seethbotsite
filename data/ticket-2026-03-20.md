## ⚡ Performance Optimizations

### 1. Large CSS Bundle
**Location:** `frontend/styles.css` (3427 lines), `frontend/theme-base.css` (1624 lines)
- **Issue:** Combined 5051 lines of CSS could be optimized.
- **Suggestion:** 
  - Implement CSS code-splitting by route
  - Use PurgeCSS to remove unused styles
  - Consider CSS modules for component-scoped styles

### 2. Polling Intervals
**Location:** `frontend/App.vue` line 71-72
- **Issue:** Rankings refresh every 30 seconds (60s in performance mode).
- **Suggestion:** Consider WebSocket-based updates instead of polling.

### 3. Rankings Polling Interval
**Location:** `frontend/App.vue` line 71-72
- **Issue:** Rankings refresh every 30 seconds (60s in performance mode).
- **Suggestion:** Consider WebSocket-based updates instead of polling.

### 4. Large Audio files
**Location:** `frontend/` - fart-with-reverb.mp3 (520KB), goose-honk.mp3 (1.8MB), newMusic.mp3 (7MB)
- **Issue:** Large audio files in frontend bundle.
- **Suggestion:** 
  - Move audio to CDN/static hosting
  - Implement lazy loading for audio files
  - Consider compressed formats (Opus/WebM)

### 5. Rate Limiter Memory Leak
**Location:** `backend/src/middleware.ts`
- **Issue:** In-memory rate limit store doesn't have max size limits.
- **Suggestion:** Add max entries limit or use lru-cache pattern.

### 6. Sync Error Handling
**Location:** `frontend/composables/useSync.ts`
- **Issue:** Errors logged to console but not surfaced to users.
- **Suggestion:** Add toast/notification system for sync errors.

### 7. Prisma Query Optimization
**Location:** `backend/src/controllers/tickets.controller.ts`
- **Issue:** Some queries could benefit from select() to reduce data transfer.
- **Suggestion:** Review all Prisma queries for unnecessary field selection.
